# Capabilities index

The organized, current-behaviour view of what Morsel does — the single source of truth
for shipped behaviour (as opposed to per-work-item specs under `docs/specs/<id>/`).
Each capability gets its own `docs/capabilities/<capability>.md`; this index links them.

_No capabilities documented yet. As work items complete, their behaviour is rolled up
here in the same PR that ships them (a workflow gate)._

Planned MVP capabilities (from the product spec §7):

- Daily fact card (claim + hook + image + citation)
- Guess-before-reveal micro-quiz
- Streaks with freeze allowance
- Accounts (gated from day one)
- Nightly content pipeline (researcher → verifier → flag-only QA → fact bank)
- Email digest reminder
- Offline card cache (service worker)
